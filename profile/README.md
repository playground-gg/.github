# playground-gg

Small, honest experiments with new models, techniques and tools — run on a laptop, written up, and shared.

This is where [Giovanni Giofrè](https://github.com/giovannigiofre) tries things out to understand how they actually behave: replicate something, change one thing, measure it, write down what happened. No novelty claims, just careful tinkering.

## How it works

- **One question per experiment.** Each repo starts from a clear question and ends with an answer, even if the answer is "it didn't work".
- **Reproducible.** Every result comes with the exact command, config, seed and hardware.
- **Laptop-first.** Most experiments run on a MacBook (Apple Silicon). If something needs more, the write-up says so.
- **Short write-ups.** Every experiment has a `WRITEUP.md`: question, setup, results, what I learned.
